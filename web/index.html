Proyecto de Paradigmas de Programación · UNA

Un lenguaje pequeño,
hecho desde cero en C.

Quimera tiene su propio lexer, parser, analizador semántico e intérprete. Esta página corre ese mismo intérprete compilado a WebAssembly: tu código se ejecuta en tu navegador, sin servidor.

Salida

    Sintaxis

    Palabras clave en inglés, bloques que cierran con End y tipos explícitos.

    Tipos 
    Integer edad = 21;
Float pi = 3.14;
String nombre = "Ana";
Char inicial = 'A';
Boolean activo = True;
Print(nombre, edad, activo);

    Una variable sin valor empieza en Null.

    Condiciones y ciclos 
    Integer nota = 75;

If (nota >= 70)
  Print("Aprobado");
ElseIf (nota >= 60)
  Print("Ampliación");
Else
  Print("Reprobado");
End

For (Integer i = 0 : i < 3 : i += 1)
  Print(i);
End

    Lógica con And, Or y Not. También While (condición) … End.

    Funciones 
    Integer cuadrado(Integer n)
  Return n * n;
End

Null saludar(String nombre)
  Print("Hola,", nombre);
End

Print(cuadrado(4));
saludar("Ana");

    El tipo de retorno va primero; Null si no devuelve nada. Admite recursión.

    Arreglos y listas 
    Integer a[3] {1, 2, 3};
a[0] = 10;

String List l;
l.append("hola");
Print(l.size());

    Los arreglos tienen tamaño fijo; las listas crecen.

    Entrada y salida 
    Integer edad;
Read(edad);
Print("En 10 años:", edad + 10);

    Print acepta varios valores y los separa con un espacio. Read lee una línea y la convierte al tipo de la variable. Comentarios con // y /* … */.

    Cómo funciona

    Cuatro etapas en C11, cada una con sus propias pruebas. Cualquier error indica línea y columna. Más detalle.

    1. 01

      Lexer

      Convierte el texto en tokens: palabras clave, identificadores, números, textos y operadores.

    2. 02

      Parser

      Arma el árbol del programa con un parser de descenso recursivo y precedencia de operadores.

    3. 03

      Analizador semántico

      Revisa tipos, scopes, declaraciones y llamadas antes de ejecutar nada.

    4. 04

      Intérprete

      Recorre el árbol y lo ejecuta. Aquí corre compilado a WebAssembly con Emscripten.
